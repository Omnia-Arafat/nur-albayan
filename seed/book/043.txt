وَلَا تَحۡزَنۡ عَلَيۡهِمۡ ; وَيَقۡبِضُونَ أَيۡدِيَهُمۡ ; هُوَ أَغۡنَىٰ وَأَقۡنَىٰ
وَأَوۡفُوا۟ بِعَهۡدِى ; حَدِيثُ ٱلۡجُنُودِ ; خَلَقۡنَا زَوۡجَيۡنِ
يَقۡرَءُونَ كِتَٰبَهُمۡ ; أَفَعَصَيۡتَ أَمۡرِى ; هُوَ أَضۡحَكَ وَأَبۡكَىٰ
وَأۡتُونِى مُسۡلِمِينَ ; كَهَشِيمِ ٱلۡمُحۡتَظِرِ ; هُوَ يُبۡدِئُ وَيُعِيدُ
وَكَرِهُوا۟ رِضۡوَٰنَهُۥ ; فَأَحۡبَطَ أَعۡمَٰلَهُمۡ ; وَيُخۡرِجۡ أَضۡغَٰنَكُمۡ
وَأَجۡلِبۡ عَلَيۡهِمۡ ; بِخَيۡلِكَ وَرَجِلِكَ ; قَالَتِ ٱلۡأَعۡرَابُ
وَإِسۡحَٰقَ وَيَعۡقُوبَ ; خُذۡهَا وَلَا تَخَفۡ ; أَكۡثَرُهُمۡ لَا يَعۡلَمُونَ
وَأَنۡ أَقِمۡ وَجۡهَكَ ; فَلۡيَدۡعُ نَادِيَهُۥ ; وَقَعَتِ ٱلۡوَاقِعَةُ
فَأَوۡجَسَ فِى نَفۡسِهِۦ ; فِرَاقُ بَيۡنِى وَبَيۡنِكَ ; يَمۡشِى عَلَىٰ رِجۡلَيۡنِ
