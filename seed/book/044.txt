أَدۡبَرَ يَسۡعَىٰ ; وَلَا يَخَافُ عُقۡبَٰهَا ; ٱلۡفَزَعُ ٱلۡأَكۡبَرُ
قَوۡسَيۡنِ أَوۡ أَدۡنَىٰ ; وَهُمۡ يَنۡهَوۡنَ عَنۡهُ ; وَيَنۡـَٔوۡنَ عَنۡهُ
وَيَعۡلَمُ مَا تَفۡعَلُونَ ; صَلَوَٰتِهِمۡ يُحَافِظُونَ ; ٱلۡقُرُونَ ٱلۡأُولَىٰ
أَظۡلَمَ وَأَطۡغَىٰ ; يَخۡطَفُ أَبۡصَٰرَهُمۡ ; يَثۡنُونَ صُدُورَهُمۡ
وَنَحۡنُ لَهُۥ مُسۡلِمُونَ ; أَسۡفَلَ سَٰفِلِينَ ; وَهُوَ ٱلۡحَكِيمُ ٱلۡخَبِيرُ

قَالَ لَا تُؤَاخِذۡنِى بِمَا نَسِيتُ وَلَا تُرۡهِقۡنِى ; وَلَا تَجۡهَرۡ بِصَلَاتِكَ وَلَا تُخَافِتۡ
يَعۡلَمُ مَا بَيۡنَ أَيۡدِيهِمۡ وَمَا خَلۡفَهُمۡ ; فَإِذَا دَفَعۡتُمۡ إِلَيۡهِمۡ أَمۡوَٰلَهُمۡ فَأَشۡهِدُوا۟
هُمۡ لِأَمَٰنَٰتِهِمۡ وَعَهۡدِهِمۡ رَٰعُونَ ; فَٱسۡتَجَبۡنَا لَهُۥ فَكَشَفۡنَا مَا بِهِۦ
