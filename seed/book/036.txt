حَدِيثُ مُوسَىٰ ; ءَامَنُوا۟ وَعَمِلُوا۟ ; وَلَا يَكَادُ يُبِينُ
فَغُلِبُوا۟ هُنَالِكَ ; فِيهَا فَوَٰكِهُ ; سَتَجِدُونَ ءَاخَرِينَ
فَيَكِيدُوا۟ لَكَ ; صَدَقُوا۟ مَا عَٰهَدُوا۟ ; نَسِيَا حُوتَهُمَا
قَالُوا۟ بَلَىٰ ; هَٰذِهِۦ بِضَٰعَتُنَا ; فِيهَا مَعَٰيِشَ
وَمَا كَانُوا۟ سَٰبِقِينَ ; قَالُوا۟ تَقَاسَمُوا۟ ; وَطُورِ سِينِينَ
يُرِيدُوا۟ خِيَانَتَكَ ; فِيهَا رَوَٰسِىَ ; كَانُوا۟ يُسَٰرِعُونَ
إِلَٰهَهُۥ هَوَىٰهُ ; وَبَٰرَكَ فِيهَا ; هَٰهُنَا قَٰعِدُونَ
فَلَا رَفَثَ وَلَا فُسُوقَ ; لَسَٰحِرَٰنِ يُرِيدَانِ ; فَلَا تَلُومُونِى وَلُومُوا۟
لَا تَقُولُوا۟ رَٰعِنَا ; فَسَلَكَهُۥ يَنَٰبِيعَ ; تَرَكَ ءَالُ مُوسَىٰ
