وَأُخَرَ يَابِسَٰتٍ ; بِسَلَٰمٍ ءَامِنِينَ ; يَخُوضُوا۟ فِى حَدِيثٍ
وَلَاتَ حِينَ مَنَاصٍ ; لَعَلَىٰ خُلُقٍ عَظِيمٍ ; فِى ٱلۡفُلۡكِ ٱلۡمَشۡحُونِ
بِحُورٍ عِينٍ ; تِجَٰرَةً حَاضِرَةً ; نَبَأَهُۥ بَعۡدَ حِينٍ
وَٱلۡقَمَرِ إِذَا تَلَىٰهَا ; وَمَثَلُ كَلِمَةٍ خَبِيثَةٍ ; لَبَنًا خَالِصًا
بِعِجۡلٍ حَنِيذٍ ; ذِى ثَلَٰثِ شُعَبٍ ; لَا يُفۡلِحُ ٱلۡكَٰفِرُونَ
يَعُوذُونَ بِرِجَالٍ ; ٱلۡأَرۡضَ مِهَٰدًا ; وَلَيَالٍ عَشۡرٍ
وَمَتَٰعًا إِلَىٰ حِينٍ ; مِيثَٰقًا غَلِيظًا ; كَيۡدَهُمۡ فِى تَضۡلِيلٍ
وَهَدَىٰهُ إِلَىٰ صِرَٰطٍ ; ذُو فَضۡلٍ عَظِيمٍ ; فِى مَقَامٍ أَمِينٍ
بُيُوتًا غَيۡرَ مَسۡكُونَةٍ ; يَهۡدِى بِهِۦ كَثِيرًا ; بِغُلَٰمٍ عَلِيمٍ
