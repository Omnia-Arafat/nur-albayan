فَلَهُمۡ أَجۡرٌ غَيۡرُ مَمۡنُونٍ ; عَجُوزٌ عَقِيمٌ ; هُوَ نَبَؤٌا۟ عَظِيمٌ
سَلَٰمٌ عَلَىٰ نُوحٍ ; فَهُوَ لَهُۥ قَرِينٌ ; هُنَالِكَ ثُبُورًا
قَالُوا۟ هَٰذَا عَارِضٌ ; خَلَقَ ٱلۡمَوۡتَ وَٱلۡحَيَوٰةَ ; وَحَفَفۡنَٰهُمَا بِنَخۡلٍ
عَلِيمًا حَكِيمًا ; قَٰنِتَٰتٌ حَٰفِظَٰتٌ ; بُهۡتَٰنٌ عَظِيمٌ
وَلَا تَزِرُ وَازِرَةٌ ; يُرۡسَلُ عَلَيۡكُمَا شُوَاظٌ ; لَا يَجِدُونَ نِكَاحًا
قَالَ هَٰذِهِۦ نَاقَةٌ ; بِٱلۡأُفُقِ ٱلۡأَعۡلَىٰ ; هَٰذَا شَىۡءٌ عَجِيبٌ
أَوۡ أَمۡضِىَ حُقُبًا ; وَلَا يُظۡلَمُونَ فَتِيلًا ; خَاوِيَةٌ عَلَىٰ عُرُوشِهَا
تَرۡهَقُهَا قَتَرَةٌ ; وَسَلَٰمٌ عَلَى ٱلۡمُرۡسَلِينَ ; فَمَا لَهُۥ مِنۡ هَادٍ
يَكُونُ لِى غُلَٰمٌ ; قَالُوا۟ سَلَٰمًا قَالَ سَلَٰمٌ ; وَمَتَٰعٌ إِلَىٰ حِينٍ
