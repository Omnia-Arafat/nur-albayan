فَخَلَقۡنَا ٱلۡعَلَقَةَ مُضۡغَةً ; فَخَلَقۡنَا ٱلۡمُضۡغَةَ عِظَٰمًا
أَخَاهُ هَٰرُونَ وَزِيرًا ; فِى هَٰذَا لَبَلَٰغًا
كَانُوا۟ مِنۡ ءَايَٰتِنَا عَجَبًا ; فَأَثَرۡنَ بِهِۦ نَقۡعًا
وَكَانَ أَمۡرُهُۥ فُرُطًا ; وَخُذۡ بِيَدِكَ ضِغۡثًا
وَكَانَ أَبُوهُمَا صَٰلِحًا ; تَصۡلَىٰ نَارًا حَامِيَةً
لَا تَرَىٰ فِيهَا عِوَجًا ; لَا رَيۡبَ فِيهِ هُدًى
لَنَرَىٰكَ فِينَا ضَعِيفًا ; بِذُنُوبِ عِبَادِهِۦ خَبِيرًا
وَجَعَلۡنَا نَوۡمَكُمۡ سُبَاتًا ; يَوۡمَ ٱلۡقِيَٰمَةِ وَزۡنًا
فَيَكُونَ مَعَهُۥ نَذِيرًا ; يَتَنَٰزَعُونَ فِيهَا كَأۡسًا
